# Experiment 01: Entity-Relationship (ER) Diagram & Relational Schema Design

## 📌 Experiment Overview

**Experiment 01** focuses on conceptual and logical database design. It covers designing an Entity-Relationship (ER) diagram and mapping entity sets, attributes, primary keys, structural cardinality constraints, and weak/strong entity relationships into a normalized relational schema.

---

## 🔑 Key Concepts Covered

1. **Entity Sets & Attributes**: Defining strong vs. weak entities, simple, composite, and multi-valued attributes.
2. **Key Constraints**: Identifying Primary Keys (PK) and Candidate Keys.
3. **Relationship Sets & Cardinality**: Mapping 1:1, 1:N, and N:M relationships with participation constraints (Total vs. Partial).
4. **Relational Schema Mapping**: Converting ER diagrams into normalized table definitions with foreign key references.
